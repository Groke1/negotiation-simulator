Арена переговоров — модуль «Обучение»

Интерактивный тренажёр навыков деловых переговоров. Пользователь проходит сценарий в формате чата, выбирает переговорные приёмы, получает разбор и видит профиль компетенций. Проект выполнен в рамках хакатона «Арена переговоров».

Концепция

Аудитория. Сотрудники, которым по роду работы нужны переговорные навыки: менеджеры по продажам, закупщики, HR-специалисты, руководители, предприниматели.

Проблема. Переговорный навык сегодня развивают либо через теорию (лекции, чек-листы, кейсы «на бумаге»), либо через дорогие очные тренинги. Дистанция между «прочитал про BATNA» и «умеет применить BATNA под давлением» ничем не закрыта. Человек получает мало попыток и редко — разбор именно своих формулировок.

Решение. Интерактивный симулятор даёт многократную безопасную практику с обратной связью на каждую попытку — без тренера на каждой сессии.

Ключевые отличия от «обычного теста». Во-первых, не оценка ответа, а оценка паттерна: правильного ответа нет, система отслеживает, как один и тот же поведенческий паттерн проявляется в разных контекстах. Во-вторых, никакого языка тестирования: в интерфейсе нет слов «тест», «балл», «правильный ответ», «ошибка» — только «тренировка», «ситуация», «решение», «наблюдение». В-третьих, во время переговоров интерфейс почти невидим: никакой обратной связи или подсказок по компетенциям, пока сессия не завершена, разбор появляется только после. В-четвёртых, один сценарий может работать в разных каналах: в MVP реализован Chat.

Функционал модуля

Прохождение тренировки в чате — ветвящийся сценарий, где реплика партнёра сменяется вариантами действий пользователя и следующей репликой. Ручной ввод и кнопки паттернов дают возможность выбрать приём или написать ответ своими словами. После тренировки идёт разбор из трёх экранов: что произошло, как вы действовали, что это говорит о компетенциях. Профиль компетенций показывает карту по шести кластерам с уровнем от 0 до 4. Динамика по сессиям — это радар с наложением последних четырёх сессий. История тренировок — список прошлых сессий с возможностью вернуться к разбору.

Шесть компетенций: цели и границы, диагностика и слушание, создание ценности и вариантов, аргументация и убеждение, торг и обмен, управление конфликтом и эмоциональная регуляция.

Уровни компетенций: 0 — не проявляется, 1 — начальный, 2 — рабочий, 3 — уверенный, 4 — адаптивный.

Сценарии

В MVP реализовано три сценария с разными ролями, сложностями и типами партнёра. Первый — продление контракта: роль менеджера по продажам, партнёр клиент, сложность L2. Второй — найм сотрудника: роль HR-специалиста, партнёр кандидат, сложность L2. Третий — переговоры с поставщиком: роль закупщика, партнёр поставщик, сложность L3.

У каждого сценария три финала: сделка закрыта, сделка не состоялась, решение отложено. Разбор зависит от финала — текст и наблюдения разные.

Механика

Ветвящийся граф работает так: узел (ситуация) содержит реплику партнёра, набор действий пользователя с паттернами и переход к следующему узлу.

Паттерны переговоров — это семантические метки действий. ASK_QUESTION — уточнить, задать вопрос. MAKE_PROPOSAL — предложить вариант. MAKE_CONCESSION — пойти на уступку. REQUEST_RECIPROCITY — запросить взаимность. HOLD_BOUNDARY — удержать границу. PAUSE — взять паузу. SUMMARIZE — резюмировать.

Определение паттерна работает так: если пользователь нажал кнопку, паттерн известен; если написал текст, фронт ищет ключевые слова по словарю; в перспективе бэк будет отправлять текст в языковую модель для точного определения паттерна.

Стек и обоснование

React и Vite — компонентный подход, быстрая сборка, горячая перезагрузка. Recharts — готовый радар для профиля компетенций. React Router — переходы между экранами. localStorage — хранение истории тренировок для MVP без бэка.

React выбран, потому что нужен компонентный подход: чат, разбор и профиль — это переиспользуемые компоненты. Recharts выбран, чтобы не писать радар с нуля: библиотека даёт готовый RadarChart с настройкой осей. Vite выбран из-за быстрой сборки и удобной разработки.

Структура проекта

В корне проекта лежат package.json, package-lock.json, vite.config.js, index.html и README.md. В папке src находятся api.js (API и мок-режим), App.jsx (роутинг), App.css (стили), main.jsx (точка входа). В папке src/data лежат scenario.js (сценарии), patterns.js (паттерны и словарь), profile.js (расчёт компетенций), history.js (история в localStorage). В папке src/pages лежат Home.jsx (список сценариев), Chat.jsx (прохождение), Debrief.jsx (разбор из трёх экранов), Profile.jsx (профиль компетенций), History.jsx (история).

Как проходить тренировку

Открыть главную и выбрать сценарий. В чате нажать кнопку-паттерн или написать текст своими словами. Отправить — партнёр ответит через 1.5 секунды. Пройти до финала и увидеть разбор из трёх экранов. Зайти в профиль и увидеть компетенции. Зайти в историю и увидеть прошлые сессии.


Границы MVP
