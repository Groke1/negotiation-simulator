# Арена переговоров

Веб-тренажер для практики деловых переговоров. Пользователь проходит сценарии в чате, выбирает и распознаёт семантические действия, а после сессии получает разбор и видит динамику компетенций.

В продукте предусмотрены три роли:

- **ученик** проходит тренировки и арены, изучает историю и профиль;
- **методист** создаёт и публикует сценарии;
- **куратор** назначает тренировки, организует арены и оставляет по ним фидбэк.

Текущий MVP поддерживает текстовый чат, подготовленные диалоги и тренировки с виртуальным партнёром.

# Запуск

Для локального запуска команда `make start`. Сервер доступен по адресу `http://localhost:3000`.

При локальном запуске не будет доступа к `LLM`.
